# MainzWare Brand Brief (durable working context)

Background carried over from earlier design conversations, kept here instead of inline in the
Marketing agent instructions so it's only loaded when actually needed.

- The company name is MainzWare.
- Finalized tagline (matches the current logo assets, `brand/M Logo Black.png` and
  `brand/M logo white.png`): `CUSTOM SOFTWARE • IT CONSULTING`. This supersedes the earlier
  `Cohesive Technology Excellence` phrase; that phrase is retired from homepage/marketing copy.
- The homepage messaging is finalized as software-first: hero -> three co-equal pillars
  (Software / Web / Consulting) -> "Beyond the Screen" (hardware, networking, cameras,
  connectivity — a secondary, on-request extension, not a headline pillar) -> "Our Approach"
  (Understand -> Design -> Build -> Refine) -> closing CTA.
- The old `HARDWARE -> SOFTWARE -> MAINZWARE` progression is retired as the homepage/messaging
  hierarchy — hardware/infrastructure is now the secondary "Beyond the Screen" story, not the
  entry point or headline framing.
- The Y-shaped Hardware+Software tiles converging into a MainzWare CPU/tile remains valid as a
  *visual composition system* for merch and system-diagram graphics (shirts, posters, social),
  where a denser technical-systems diagram is appropriate. It is not the homepage content
  hierarchy described above.
- The desired back-of-shirt composition is a portrait technical graphic with Hardware and
  Software tiles, readable bullet points, a Y-shaped circuit path, and a larger MainzWare
  CPU/tile at the convergence point.
- The same design language should extend to homepage headers, hero graphics, T-shirts, hats,
  posters, and social graphics.

Chat history itself cannot be moved automatically between agents. Treat this file and the
